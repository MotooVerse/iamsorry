# Cinematic Gift Website

Files:
- index.html — complete website
- gift-photo.png — the image used in Gift 01

To preview: open index.html in a browser.

For GitHub Pages:
1. Put both files in the repository root.
2. Commit and push.
3. In GitHub, open Settings → Pages.
4. Select the main branch and root folder.
5. Save, then open the Pages URL GitHub provides.

You can edit the apology paragraph and the five cute reasons directly in index.html.
